# Arabic-English Transcript RAG Chatbot

This project is a Retrieval-Augmented Generation chatbot built with Streamlit and LangChain.  
It answers questions based only on Arabic-English transcript episodes.

## Features

- Arabic-English transcript retrieval
- Multilingual embeddings
- Chroma vector store
- Multi-turn conversation
- Sliding-window memory
- Strict grounded prompting
- Out-of-domain rejection
- Groq primary LLM
- OpenRouter fallback LLM
- Streamlit interface with logs
